# Asset Sources

The prototype block textures are derived from GregTech 6 assets in the parent project:

- `machine_casing.png`: `materialicons/METALLIC/casingMachine.png`
- `machine_port.png`: `multiblockparts/metalwall/1/colored/side.png`
- `large_crusher_*.png`: `multiblockmains/largeboiler/colored*`
- `lv_generator_*.png`: `energystorages/battery_electric/colored*`
- `basic_crusher_*.png`: `basicmachines/crusher/colored/*`
- `electric_motor_*.png`: `motors/rotation_electric/colored/*`
- `electric_engine_*.png`: `engines/kinetic_electric/colored/*`
- `rotation_engine_*.png`: `engines/kinetic_rotation/colored/*`
- `manual_crank_front.png`: `tools/crank/colored/front.png`

GregTech 6 assets are released under CC0 unless the original asset states otherwise. See the parent project's `src/main/resources/LICENSE.assets`.

The tin cable, copper cable, axle, generated crank side, wrench, screwdriver, soft hammer, magnifying glass, monkey wrench, and electrometer textures are small generated placeholders created for this port.
